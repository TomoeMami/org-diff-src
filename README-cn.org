Org 会用 [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Diff-Mode.html][Diff mode]] 渲染 ~diff~ 源码块，但其中的细粒度高亮通常会消失：
Org 只从用于字体化源码块的临时缓冲区复制 font-lock 的 ~face~ 属性，而 Diff
mode 的 refinement（细化）保存在 overlay 里。~org-diff-src~ 提供
~org-diff-src-mode~：一个派生自 ~diff-mode~ 的小模式，它把同样的细化记录为
~face~ 文本属性，因此发生变化的字词在 Org 缓冲区中仍然带有颜色。

渲染结果是普通的 Org 源码块，可以折叠、编辑和导出，也不会启动 Ediff 会话。
diff 可以来自两个字符串、两个文件、两个缓冲区或两个 Org 子树。通过三行配置，
本包还可以接管所有 ~diff~ 源码块的默认显示方式。

#+caption: Org 源码块中的 Diff mode 细化效果。截图使用 ~ediff~ 别名；完成最简配置后，普通 ~diff~ 源码块看起来是一样的。
[[file:images/org-diff-src-example-cn.png]]

如果希望独立实现相同行为，可参阅 [[file:CLEAN-ROOM-cn.org][净室规格]]（英文：
[[file:CLEAN-ROOM.org][CLEAN-ROOM.org]]）。

* 功能

- 把任意 unified diff 渲染为 Org 源码块。
- 在 Org 缓冲区中保留 Diff mode 的细化，而不只是整行的新增/删除 face。
- 用 ~diff-refine-removed~ 、 ~diff-refine-added~ 和 ~diff-refine-changed~
  为发生变化的字词（以及词内变化的字符）上色。
- 通过内置的 ~org-diff-src~ 语言工作，无需额外配置。
- 通过三行配置接管已有的 ~diff~ 源码块。
- 比较两个 Org 子树、两个文件或两个缓冲区。
- 复制子树时不修改 kill ring 或系统剪贴板。
- 不启动 Ediff 会话，除 Org 和 Diff mode 外不依赖其他包。
- 使用标准补全界面，不要求 Consult。
- 如果 Diff mode 的细化内部接口发生变化，退回行级高亮。

* 环境要求

- Emacs 27.1 或更高。Emacs 27.1 自带的 Org 9.3 已经足够。
- 一个 ~diff~ 可执行文件。推荐 GNU diffutils。程序会优先使用 ~--label~ ，
  不可用时退回可移植的 ~-L~ 选项。

* 最简配置：接管 diff 源码块

本包默认不改变 ~diff~ 源码块，只新增 ~org-diff-src~ 语言。如果希望所有
~diff~ 源码块都使用 ~org-diff-src-mode~ ，并让新插入的源码块使用 ~diff~
语言，在 init 文件中加入三行：

#+begin_src emacs-lisp
(require 'org-diff-src)                     ; 加载本包和 Org
(org-diff-src-setup '("diff"))              ; diff -> org-diff-src-mode
(setq org-diff-src-default-language "diff") ; 新插入的块使用 diff
#+end_src

第二行是真正的接管。Org 默认把 ~diff~ 解析为 ~diff-mode~ ，因此 ~diff~ 块
只有整行的新增/删除 face；把 ~diff~ 映射到 ~org-diff-src-mode~ 后，才会
获得 Diff mode 的细化。该映射对已有和新建的源码块都生效；已经显示出来的块会
在下一次字体化时细化，也可以立即执行 =M-x org-diff-src-refontify-block= 。

第三行只改变 ~org-diff-src-insert~ 和比较命令写入的语言。省略它，新块仍然
使用 ~org-diff-src~ 语言；[[*使用][使用]] 中的示例假定使用这个默认值。

这是显式选择：所有 ~diff~ 源码块都会受影响，包括其他包生成的块。
~org-diff-src-mode~ 派生自 ~diff-mode~ ，所以 =C-c '= 编辑、hunk 命令、
导航和折叠都仍然可用。要恢复原有 ~diff-mode~ 显示，请删掉第二行，并把
~org-diff-src-default-language~ 改回 ~"org-diff-src"~ 。只有 unified diff
会被细化。

** 使用 use-package

不要延迟加载：映射必须在 Org 第一次字体化 ~diff~ 块之前就已经安装。

#+begin_src emacs-lisp
(use-package org-diff-src
  :straight (:type git :host github :repo "TomoeMami/org-diff-src")
  :demand t
  :config
  (org-diff-src-setup '("diff"))
  (setq org-diff-src-default-language "diff"))
#+end_src

** 不接管 diff 源码块

内置的 ~org-diff-src~ 语言无需额外配置：

(require 'org-diff-src)

#+end_src

* 使用

** 比较两个 Org 子树

打开一个 Org 缓冲区，执行：

=M-x org-diff-src-compare-headings=

先选择原始标题，再选择新标题。两个子树会在不修改 kill ring 和系统剪贴板
的情况下被复制，统一提升到一级标题，用 ~diff~ 比较，然后以
~org-diff-src~ 源码块的形式插入到光标处。

例如，对于下面的内容：

#+begin_src org
,* Original
Some text.
foo bar baz

,* New
Some text.
foo BAR baz
#+end_src

依次选择 =Original= 和 =New= 后，会得到：

#+begin_example
#+begin_src org-diff-src
--- original: Original
+++ new: New
@@ -1,3 +1,3 @@
-* Original
+* New
 Some text.
-foo bar baz
+foo BAR baz
#+end_src
#+end_example

发生变化的字词（ =Original= / =New= 以及 =bar= / =BAR= ）会使用 Diff mode
的细化 face 上色。标题行也属于比较范围，因此标题本身的变化也会出现在差异中。

** 语言名与别名

默认源码语言是 ~org-diff-src~ 。Org 会自动把它解析为
~org-diff-src-mode~ ，因此新生成的 ~org-diff-src~ 源码块不需要额外配置。

如果你已经有写成 ~ediff~ 的源码块（例如来自最初的 snippet），注册一次别名
即可：

#+begin_src emacs-lisp
(require 'org-diff-src)
(org-diff-src-setup)
#+end_src

~org-diff-src-setup~ 会把 ~org-diff-src-extra-languages~ （默认
~("ediff")~ ）中的每个语言映射到 ~org-diff-src-mode~ 。请在 Org 字体化
这些源码块之前执行。

如果希望新插入的源码块也使用 ~ediff~ ：

#+begin_src emacs-lisp
(setq org-diff-src-default-language "ediff")
#+end_src

也可以显式注册更多别名：

#+begin_src emacs-lisp
(org-diff-src-setup '("ediff" "diff"))
#+end_src

接管 ~diff~ 源码块的完整配置见 [[*最简配置：接管 diff 源码块][最简配置]]。

** 渲染已有的 diff

- 复制一段 diff（例如从 Magit 中复制），然后执行
  =M-x org-diff-src-insert-from-kill= 。
- 选中 diff 文本，执行 =M-x org-diff-src-wrap-region= ，用带高亮的源码块
  替换该区域。
- 执行 =M-x org-diff-src-insert-diff-file= ，把 diff 文件的内容插入为
  源码块。

** 比较文件或缓冲区

- =M-x org-diff-src-compare-files= 会依次询问原始文件和新文件。
- =M-x org-diff-src-compare-buffers= 会依次询问原始缓冲区和新的缓冲区。

两个命令都会把结果插入当前 Org 缓冲区的光标处。

** 重新字体化源码块

Org 通常会在源码块被编辑后重新字体化。如果 Lisp 代码修改了源码块却没有触发
字体化，请执行：

=M-x org-diff-src-refontify-block=

* 命令

| 命令                            | 用途                              |
|---------------------------------+-----------------------------------|
| ~org-diff-src-setup~            | 注册 ~ediff~ 等语言别名。         |
| ~org-diff-src-compare-headings~ | 比较当前 Org 缓冲区中的两个子树。 |
| ~org-diff-src-compare-files~    | 比较两个文件。                    |
| ~org-diff-src-compare-buffers~  | 比较两个缓冲区。                  |
| ~org-diff-src-insert-diff-file~ | 把 diff 文件插入为源码块。        |
| ~org-diff-src-insert-from-kill~ | 把当前 kill 插入为源码块。        |
| ~org-diff-src-wrap-region~      | 用源码块替换当前区域。            |
| ~org-diff-src-refontify-block~  | 重新字体化光标处的源码块。        |

* Lisp API

生成 diff 和插入的函数与交互命令相互独立，因此可以在其他包中直接使用。

- ~(org-diff-src-insert DIFF &optional LANGUAGE)~ :: 把 ~DIFF~ 作为带高亮的
  源码块插入光标处。~LANGUAGE~ 默认为 ~org-diff-src-default-language~ ，
  并且必须映射到 ~org-diff-src-mode~ ；内置的 ~org-diff-src~ 语言会自动
  满足这一点。返回源码块之后的位置。如果 ~DIFF~ 为 nil 或空字符串，插入
  ~org-diff-src-no-diff-message~ 。
- ~(org-diff-src-setup &optional LANGUAGES)~ :: 把 ~LANGUAGES~ （默认
  ~org-diff-src-extra-languages~ ）注册到 ~org-diff-src-mode~ 。返回已注册
  的语言列表。
- ~(org-diff-src-diff-strings OLD NEW &optional OLD-LABEL NEW-LABEL CODING)~ ::
  返回字符串 ~OLD~ 和 ~NEW~ 之间的 unified diff。
- ~(org-diff-src-diff-files OLD-FILE NEW-FILE &optional OLD-LABEL NEW-LABEL)~ ::
  返回两个文件之间的 unified diff。远程文件会先复制到本地。
- ~(org-diff-src-diff-buffers OLD-BUFFER NEW-BUFFER &optional OLD-LABEL NEW-LABEL)~ ::
  返回两个缓冲区完整内容之间的 unified diff。
- ~org-diff-src-mode~ :: 源码块使用的主模式。它派生自 ~diff-mode~ ，把
  ~diff-refine~ 设为 ~font-lock~ ，并把细化记录为文本属性。

示例：

#+begin_src emacs-lisp
(with-current-buffer (get-buffer-create "*diff-demo*")
  (org-mode)
  (org-diff-src-insert
   (org-diff-src-diff-strings
    "The quick brown fox\n"
    "The quick red fox\n"
    "before" "after")))
#+end_src

以编程方式比较两个缓冲区：

#+begin_src emacs-lisp
(org-diff-src-insert
 (org-diff-src-diff-buffers (get-buffer "notes-a")
                            (get-buffer "notes-b")
                            "before" "after"))
#+end_src

默认源码语言是 ~org-diff-src~ ；Org 会通过 ~org-src-get-lang-mode~ 把它
解析为 ~org-diff-src-mode~ ，因此不需要修改 ~org-src-lang-modes~ 。通过
~org-diff-src-setup~ 注册的别名也会以同样的方式解析。

* 实现原理

Org 在字体化源码块时，会从临时缓冲区复制 font-lock 的 ~face~ 文本属性，
但不会复制 overlay。而 Diff mode 的细化高亮是用 overlay 实现的，所以直接
把 diff 放进 Org 时，细化高亮通常会丢失。

~org-diff-src-mode~ 的处理方式是：

1. 从 ~diff-mode~ 派生。
2. 把 ~diff-refine~ 设为 ~font-lock~ ，让 font-lock 计算细化结果。
3. 把 ~diff-font-lock-keywords~ 中的 ~diff--font-lock-refined~ 替换为自定义
   函数，把细化 overlay 的 face 复制为 ~face~ 文本属性。
4. Org 的 ~org-src-font-lock-fontify-block~ 随后就能把这些属性复制到 Org
   缓冲区中。

如果未来的 Emacs 移除了 Diff mode 的细化内部接口， ~org-diff-src-mode~ 会
保留普通的行级高亮，而不是直接报错。

这也是默认源码语言使用 ~org-diff-src~ 而不是 ~diff~ 的原因： Org 会把
~diff~ 解析为普通的 ~diff-mode~ ，除非你显式把它注册为别名。参见
[[*最简配置：接管 diff 源码块][最简配置]]。

* 自定义

- ~org-diff-src-diff-switches~ :: 传递给 ~diff-command~ 的参数，默认是
  ~("-u")~ 。如果添加其他参数，请保留 ~-u~ ，因为细化代码需要 unified
  diff。
- ~org-diff-src-no-diff-message~ :: 差异为空时插入的文本，默认是
  ~# No differences~ 。
- ~org-diff-src-default-language~ :: 插入源码块时使用的语言，默认是
  ~"org-diff-src"~ 。
- ~org-diff-src-extra-languages~ :: 由 ~org-diff-src-setup~ 注册的语言，
  默认是 ~("ediff")~ 。
- ~org-diff-src-fontify-immediately~ :: 是否在插入源码块后立即字体化，
  默认是 ~t~ 。对于很大的 diff，可以设为 nil。
- Face :: 细化高亮使用 ~diff-refine-removed~ 、 ~diff-refine-added~ 和
  ~diff-refine-changed~ 。可以通过 =M-x customize-face= 或在
  ~custom-set-faces~ 中自定义。

该模式只在缓冲区局部设置 ~diff-refine~ ，不需要修改它的全局值。执行
=M-x customize-group RET org-diff-src RET= 可以查看全部选项。

* 限制

- 只会细化 unified diff。Context diff 和 normal diff 会作为普通文本显示。
- 细化颜色是 Emacs 的显示属性。把 Org 文件导出为 HTML 或 PDF 时，diff
  文本仍会保留，但不一定保留细化颜色。
- 很大的 diff 在字体化时可能较慢，因为细化是按 hunk 和字词计算的。
- 差异两侧的标签会被压缩成一行。
- 如果未来的 Emacs 移除了 Diff mode 的细化内部接口，本包会退化为行级高亮。
- ~org-diff-src-compare-headings~ 比较的是完整子树，包括标题行。如果只想
  比较部分正文，可以使用 ~org-diff-src-diff-strings~ 。
- 本包用于渲染静态 diff，不能替代 Ediff 或 Magit 的交互式合并功能。

** 扩展新的 diff 来源

producer 就是一个返回 unified diff 字符串的函数。例如：

#+begin_src emacs-lisp
(defun my/org-diff-src-from-git (rev-a rev-b)
  "Return a unified diff between REV-A and REV-B."
  (with-temp-buffer
    (let ((status (call-process "git" nil t nil
                                "diff" "-u" (concat rev-a ".." rev-b))))
      (unless (memq status '(0 1))
        (error "git diff failed: %s" (buffer-string))))
    (buffer-string)))

(org-diff-src-insert (my/org-diff-src-from-git "HEAD~1" "HEAD"))
#+end_src

渲染层只关心 unified diff 文本，因此新的 producer 不需要修改
~org-diff-src-mode~ 。
